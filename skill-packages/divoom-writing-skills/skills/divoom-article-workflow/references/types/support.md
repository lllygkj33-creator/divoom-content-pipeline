# 帮助与提示｜正文写作规范

**本栏目正文主线：** 安全或损失边界 → 按症状分流 → 可逆检查 → 恢复验证 → 何时停止、换件或求助。

## 1. 文章承诺

读完必须让用户**恢复**：能按症状分流、做可逆检查、确认是否修好。

## 2. 开头

用 2 段约 75–115 个英文词完成入口，参照本栏目 23 篇样本开头中位 2 段、93 词。第一段先交代“哪些迹象出现就立即停止使用”，若无安全征兆，则给最先做的一项无损检查及其观察结果；不能用故障成因科普延迟行动。第二段用症状和检查所得结果给出简短分流：看到 A 进入哪类检查，看到 B 跳到哪类检查，完全不符合则何时求助；不要在未确认症状时保证修复。

品牌只在确需指认适用设备时出现，开场不推产品；样本品牌提及中位仅 2 次，不把它变成强制配额。

**本栏目不做：** 不解释不必要的原理、不做同轴决胜、不做购买决策。

## 3. 正文推进

按既定 H2 所承担的症状或检查环节写。节首用一句“适用迹象／不适用迹象”锁定读者，接着给停止条件，再列最常见、可逆且能排除一种原因的检查；罕见或不可逆处理放在最后并给升级出口。每项检查写成“做什么—观察什么—若是／若否往哪里走”，不得只有动作没有结果。节末单写可验收句：“若观察到 X，恢复到 Y；否则停止该分支并转向 Z”，不能以“试试其他方法”收场。

普通 H2 以 3–5 个正文段落、约 115–185 个英文词为带宽，本栏 23 篇中位为 4 段、145 词。分流与检查优先清单：样本带清单的节 53 个、表格仅 5 个；清单能保持操作先后和停止节点，表格易使读者横向跳步。每次升级都注明触发症状与接收方，避免循环重试。全文 1200–2200 英文词，不写 H3。

## 4. 证据与产品提及

将症状、恢复状态与`实体库/状态与症状`核对；检查对象回`部件`、`接口与依赖`和`功能与能力`；使用条件与升级风险回`条件与限制`、`结果与风险`。数字只能取`指标与阈值`中可定位的条目；无条目便删除，不估算，也不加“约”。涉及电气与电池、安装与坠落、防水与进水、儿童与隐私，在对应检查前就地写明确停用条件，然后才写处理和验收，不把警示集中挪到文末。

指代 Divoom 优先用实体库已有的品类或部件词；型号名以 `../品牌资料库/产品/` 的官方命名为准，自创或拼错的型号名是硬伤；一般指代优先用品类或部件词。随附配件与是否可单买只写“以商品页为准”。Momcozy / KTC 的正文仅作分流和验证的结构参照，其产品事实、参数、医疗建议、测试结论、链接不得进入文章或本规范实例。不得写价格、品牌排名、“绝对最佳”；编辑稿不写内链、meta、FAQ。

## 5. 栏目专属结尾

给**恢复／升级条件**：说明什么状态算已恢复，什么情况下应停止自行处理、换件或求助。
