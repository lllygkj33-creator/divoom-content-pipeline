# 链接规范

先按语义选目标，再写锚。博客解释相邻子问；品类集合承接真实品类需要；PDP 核对具体型号能力。内链池在 `source/内链索引/`；页面表仅允许用途为品类且实际可用的类别/场景页，不用促销集合。不要根据 slug 猜网页事实。

共享锚文本类型/长度和所选类型侧重见 [原总规范](source/锚文本总规范.md) 与各 `source/<类型>/锚文本规范.md`。这些统计是建议，不是配额。主用3–6词；集合词2–4；产品用官方名可到10；长主张锚只在确有需要时用。每个锚必须符合目标正文的实际覆盖范围。

外链以事实支持关系为准；来源必须实际读过，不能仅搜索摘要或HTTP成功。第三方遵守 publisher 属性契约。品类变体可共享同集合，不要求一个关键词建一个页面。

links.json 为数组：href/kind/anchor/section/purpose/checked_at/verification/source_locator。每条实际 HTML 链接必须有相同 href 与 anchor 的 verified 行；多次出现分别记录。pending 只能在内部记录，href 留空，不把“待补链接”文字放进正文。相对链接对应真实绝对目标核验并在 source_locator 写明；纯页内锚必须指向存在 id。

相邻文章、商业页面和外部证据各有用途，不能互相替换充数。无最低内链或外链数量；需要外部证据的关键主张不能因为无配额而略过。内链密度只统计自家链接，超过1.5/百词按质量规范检查，不把外链混算。正文不新增“阅读更多”填充段、不照搬竞品链接、不插当前文章自己的预期URL。
