1. 直接结论

  1. 先绑定对应 FX，再借鉴写法。同品牌、同主题或相同页面布局不等于相同写作类型。此前以孕期旅行文替代 F1 是基准选择错误。
  2. 段落变化的依据是职责，不是长短随机变化。样本中既有四段一节，也有两段、六段和以表格／清单为主的节。应检查新增变量、观察与边界，不把“四段”直接判为机械。
  3. 小条件必须使判断不同。环境、时间窗、版本、个体差异和使用阶段服务于解释，不为多场景配额换地点。
  4. 图位与大纲同时规划。43 张正文图有 41 张位于所在小节前三个实质段落内，另外包括开头两段后的图。图的任务是把难以只靠文字说明的差异具体化；不能据此规定每 H2 一张。
  5. 不把参考作品当绝对质量标准。已发现图中文字、编号、alt 和图文信息量问题；借鉴其功能，同时设置质量检查。

2. 样本与统计口径

逐篇读取规范登记 URL。识别 editorial 与 classic 两种正文模板；只统计正文容器，段落不含列表项、表格单元格和商品卡中的 p。封面采用页面 OG 资产识别，不自动等同实际 banner；广告、头像、订阅图和侧栏不计正文图。

正式样本有 13 张 OG／封面资产、43 张正文图；F10 另含两个商品卡的 4 张主图／悬停图节点。F14 补充候选有 1 张封面与 1 张正文图。共取得并查看 62 张资产。每个子类型只抽取其登记案例，足以检查当前映射，不能据此推断 Momcozy 所有文章的固定频率。

3. 配图类型、出现位置与用途

类型样本中的任务适合位置Divoom 迁移约束
机制／剖面图把部件职责、传递路径和限制可视化先说明问题与关键术语，再进入路径解释用适用型号官方结构或明确通用示意；不生成虚构内部构造
条件／结果对照图让相似指标、不同结果并排可见指标错位或条件切换的位置固定比较轴，不把不同响度、场景或设备条件混成结论
部件／检查点图把抽象因素接到可观察位置解释因素之后、进入检查之前箭头指向真实部件；每个检查点需要对应正文依据
阈值／曲线／读数图展示基线、变化、时间窗或区间定义指标和条件之后先有数据与口径再画图；无实测不伪造曲线或阈值
过程／时间线图表达先后依赖、阶段变化和工作约束步骤或状态转换的说明处只标真正变化的节点；实际设备步骤核对手册
场景／细节照片给环境约束、动作或结果一个具体背景环境条件首次影响判断的位置场景图不是功效或实测证据，优先可观察细节而非泛装饰
封面与商品卡封面用于识别文章，商品卡用于商业分流栏目卡片或模板固定区域不混入正文解释图统计；带大标题的封面不直接当 H1 背景
同一个机制可以“短答案 → 情境差异 → 图解 → 读者应看什么”，也可以“短答案 → 一张同轴表 → 边界”。这是按问题选择表现方式，不是新的固定四段模板。

4. 反例：借鉴组织，不照搬错误

已核对的可见问题包括 A009 的编号重复、A016 的百分号排版、A034 的图内用词与主题不一致、A038 缺少可读的坐标与读数、A048 勺喂画面与瓶喂 alt 不符。A041 是现代场景照片，不能当作早期监护器的历史图证。涉及医学或数值的图，本次不裁定其专业结论，迁移时需要独立核实。

这要求 visual plan 不只写“这里放图”，还写明图要解释的变量、图内事实依据、实际素材状态和位置；入稿前查看像素，不能依赖文件名和 alt 自动认定内容。

5. 如何微调段落、条件和场景

段落：逐段标注它新增的答案、机制、条件、观察或边界。相邻两段若只把“不能仅凭参数判断”换个说法，合并；若分别限制不同推断则保留。不是为了节奏而随机缩短句子或打散因果链。

条件：每个场景记录改变什么、保持什么、看到什么、这个观察最多说明什么。仅从“桌面”换成“卧室”而判断相同，通常不值得单独占节。

FAQ：按未解决问题决定；6/13 有并不代表所有文章必须有。F1 样本和当前功率文章均可不加。FAQ 不能用来重复主标题答案。

配图：写之前决定论证任务与图位，素材没有就保留内部计划，正文先独立成立。最终 JSON 不包含图位占位符、提示词或未核实 URL。

以功率文章为例保持不变改变的条件需要回答的观察问题
音量条件同一音箱、音源、位置正常与更高播放音量低音相对其他频段的变化是什么？不声称已完成实测。
环境条件同一音箱与播放设置靠近边界与另一位置特定音符的变化是否提示环境参与？不直接诊断处理算法。
观察目标相同比较任务低频延伸、鼓点突出或可用低音音量读者说的“更多低音”究竟是哪一种结果？
